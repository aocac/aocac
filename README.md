## 关于

主业之外写代码，做得最多的是 Windows 桌面小工具和效率软件。对软件的判断标准很简单：轻快、干净、不打扰，自己的项目也照这个标准来做。

同时运营个人博客 [软件鸭](https://ruanjianya.net/)，持续分享 Windows 绿色软件、开源替代品和效率工具的更新与用法——PE 工具箱怎么选、7-Zip 和 Bandizip 谁更顺手、LocalSend 怎么局域网互传，这类话题是站里最常写的。

## [GameTalk](https://github.com/aocac/GameTalk)

游戏内的轻量群组通信工具，边玩边聊，不用切窗口。

- **全局快捷键呼出**，透明消息悬浮层叠在游戏画面上，不挡视野
- **多房间**，队内、公会、朋友各一条频道，互不干扰
- 基于 **Tauri 2** 构建，安装包小、常驻内存低；服务端 Fastify + PostgreSQL
